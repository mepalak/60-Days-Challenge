# 📄 PDF Splitter & Merger

A simple and user-friendly **PDF Splitter & Merger** application that allows users to split large PDF files into smaller documents and merge multiple PDFs into a single file. Designed with an intuitive interface, this project demonstrates efficient PDF manipulation using modern web technologies.

---

## 🚀 Features

- 📂 Upload one or multiple PDF files
- ✂️ Split PDF by page range
- 📑 Merge multiple PDFs into a single document
- ⚡ Fast and efficient PDF processing
- 💾 Download processed PDF instantly
- 🖥️ Clean and responsive user interface
- 🔒 Secure processing without storing files

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- PDF-Lib / PDF.js
- File API

---




## 📖 How to Use

### Split PDF

1. Upload a PDF file.
2. Enter the page range.
3. Click **Split PDF**.
4. Download the generated PDF.

### Merge PDFs

1. Upload multiple PDF files.
2. Arrange them if needed.
3. Click **Merge PDFs**.
4. Download the merged document.
