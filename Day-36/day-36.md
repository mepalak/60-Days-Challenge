# Day 36 – Explore Your Thinking Patterns with Cognitive Pattern Explorer

## 📌 Challenge Overview

Welcome to **Day 36** of the **60 Days of Claude AI Challenge**!

Today's challenge is about understanding **how you think, reason, and make decisions** by building an interactive **Cognitive Pattern Explorer**. Instead of simply answering questions, Claude AI helps create a visual experience that reveals thinking styles, cognitive biases, decision-making patterns, and problem-solving approaches through engaging scenarios and assessments.

This project demonstrates how AI can be used to build educational applications that encourage self-awareness and critical thinking while showcasing modern frontend development skills.

---

# 🎯 Objective

Build an interactive **Cognitive Pattern Explorer** that enables users to:

- Discover their thinking style.
- Analyze decision-making patterns.
- Identify common cognitive biases.
- Explore different problem-solving approaches.
- Receive personalized insights and recommendations.
- Learn strategies for improving critical thinking.
