# 🧭 Day 37: Build Task Compass

> **Navigate Complex Projects with AI-Powered Task Prioritization**

## 📌 Overview

Welcome to **Day 37** of the **60 Days of Claude AI Challenge!**

Today's challenge is to build **Task Compass**, an AI-powered productivity assistant that helps users prioritize tasks, organize workflows, and make smarter decisions about what to work on next.

Instead of relying on a basic to-do list, Task Compass analyzes task urgency, importance, deadlines, dependencies, and estimated effort to generate an intelligent action plan.

---

# 🎯 Objectives

- Learn AI-assisted task prioritization
- Build an intelligent productivity dashboard
- Understand the Eisenhower Matrix
- Organize tasks using dependencies
- Improve planning with AI recommendations
- Practice modern frontend development

---

# 🚀 Features

## 📋 Smart Task Manager

- Add, edit, and delete tasks
- Organize tasks by category
- Set priority levels
- Add deadlines
- Estimate task duration
- Tag related tasks

---

## 🧠 AI Priority Engine

Claude analyzes:

- Importance
- Urgency
- Task dependencies
- Estimated effort
- Deadlines
- Workload balance

Then recommends whether to:

- ✅ Start Now
- 📅 Schedule Later
- 🤝 Delegate
- ❌ Eliminate

---

## 🧭 Task Compass Dashboard

Interactive dashboard displaying:
